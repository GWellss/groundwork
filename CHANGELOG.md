# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-09

First public version.

### Added

- 24 component specifications in `components/`: button, chip, tooltip, divider, link, badge, avatar, progress, text-field, search-field, checkbox, radio, switch, slider, segmented-control, tabs, accordion, menu, select, popover, dialog, alert, toast, card.
- Rationale files in `docs/rationale/`, explaining the decisions for human contributors.
- Shared documentation in `docs/`: conventions, glossary, and implementation guide for code generation.
- A theme questionnaire in `theme/questionnaire.md`, with three levels depending on the tools an agent has.
- A theme script, `theme/theme.py` (Python standard library only), that generates `DESIGN.md`, `tokens.css`, and a contrast report from the questionnaire answers. With the optional dark mode it also generates `DESIGN.dark.md` and a `[data-theme="dark"]` block in `tokens.css`. It includes a built-in check, `--selftest`.
- Color palette reference in `theme/palettes.md`, for agents without tools.
- Example themes in `examples/`, generated by the theme script: `examples/default/` (light) and `examples/default-dark/` (light and dark, with `DESIGN.md`, `DESIGN.dark.md`, and a `tokens.css` holding a light block and a `[data-theme="dark"]` block).
- `--version` option of the theme script, which reports version 0.1.0.
